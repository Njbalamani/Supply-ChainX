SupplyChainX

SupplyChainX is an enterprise software supply-chain security intelligence platform. It builds CycloneDX SBOMs from uploaded source archives, queries real vulnerability intelligence sources, analyses transitive dependency risk with NetworkX, and presents prioritized remediation guidance.

Trust principles

  • No code execution: uploaded archives are only read as data; contained source is never run.
  • No fabricated advisories: CVE/GHSA findings come from live OSV.dev queries, optionally enriched by NVD. Source attribution is stored per finding.
  • Tenant isolation: all project data is scoped to organization membership.
  • Auditable output: SBOM JSON, vulnerability CSV, PDF reports and source-status logs are reproducible per scan.

Quick start

Create an organization, register a project, upload a ZIP containing requirements.txt, package.json/package-lock.json or pom.xml, then open the resulting scan to review findings.
