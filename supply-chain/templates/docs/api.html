Authentication

Obtain a DRF token, then send it as Authorization: Token <token>.

curl -X POST http://localhost:8000/api/auth/token/ \ -d "username=analyst&password=your-password"

Core endpoints

MethodEndpointDescription
GET/POST/api/organizations/List or create organizations.
POST/api/projects/{id}/upload/Multipart upload of a source ZIP; creates and queues a scan.
POST/api/scans/{id}/queue/Re-queue a pending or failed scan.
GET/api/scans/{id}/summary/Risk, health, graph and license summary.
GET/api/dependencies/Parsed components with purls and source manifests.
GET/api/vulnerabilities/Advisory findings with source attribution.
GET/api/recommendations/Grounded remediation guidance.
GET/api/intel-sources/Health of OSV, NVD and optional local tools.
GET/api/dashboard/summary/Aggregate security posture for the current user.

Machine-readable schema

The complete OpenAPI document is available at /api/schema/. All list endpoints are paginated (25 items per page) and scoped by organization membership.

Exports

Authenticated HTML views provide /reports/scans/<id>/report.pdf/, /reports/scans/<id>/vulnerabilities.csv/, /reports/scans/<id>/sbom.json/ and /reports/scans/<id>/graph.json/.
